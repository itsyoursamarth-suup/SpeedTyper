# ⚡ SpeedTyper

A sleek, minimal dark-mode **Typing Speed Test** web application built using **HTML5, CSS3, and Vanilla JavaScript**.

## ✨ Features
- **Multiple Practice Modes:** Switch between standard English sentences, programming/code quotes, and mixed mode.
- **Custom Timer:** Practice with **30s** or **60s** countdown options.
- **Live Feedback:** Real-time character highlighting (correct/incorrect), live **WPM**, and **Accuracy %** calculation.
- **High Score Tracking:** Automatically saves your personal best WPM in `localStorage`.
- **Keyboard Shortcuts:** Quick restart using `Esc` or `Tab + Enter`.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Deployment:** GitHub Pages
